# CoTend v0.1.0-rc.2

CoTend v0.1.0-rc.2 is an unpublished GitHub Open Beta update candidate. It is a Pre-release and not a stable release.

## What is included

- Eight Codex Skills, including a direct writable Semantic Alignment entry with deterministic decision-log binding.
- The complete adopted Dual AI behavior range from v1.53 through v1.65, adapted for CoTend's public Full default and persistent user profile choice.
- Runtime profiles, native-agent orchestration, delegation maturity, semantic implementation closure, content-freshness checks, and current actual-model identity reporting.
- A deterministic 48-file skills-only Plugin package with Apache-2.0 first-party licensing and preserved third-party MIT notices.
- A trusted update path from the locked seven-Skill `r000001` carrier to the eight-Skill `r000002` carrier.

## Install

Follow the [GitHub Open Beta instructions](../../README.md#install-from-github-open-beta). Until this candidate is separately approved and pushed, those commands continue to install the previously published repository revision.

## Verification

The release asset is built from the locked package contract. The accompanying `.sha256` file records the ZIP digest. Unit tests, repository checks, package verification, predecessor-update checks, and submission-material verification must pass before a draft release can be created.

## Known boundaries

- This candidate has not been tagged, pushed, submitted, released, or published.
- The Public Plugin Directory has not reviewed or executed the five positive and three negative submission cases.
- Existing-task catalog refresh and complete Desktop lifecycle coverage remain beta work.
- No CoTend account, hosted backend, API key, database, or MCP server is included.
