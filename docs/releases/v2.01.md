# CoTend v2.01

CoTend v2.01 是面向 Codex 的 GitHub Open Beta 更新。这是一个 Pre-release，不是稳定版（not a stable release）。Codex Plugin 包内采用严格 SemVer `2.1.0-beta.1`，对应 CoTend 产品版本 `v2.01` 与本地 artifact `cotend-codex-r000017`。

## 本版包含

- 10 个 Codex Skills、104 个 Skill 文件：8 个 CoTend 自有 Skills，以及保留原名和 MIT 归属的 Grill Me、Karpathy Guidelines。
- CoTend Semantic Alignment、Project Intelligence 与 Plan Tree 共同维持产品语义、项目位置和活动路线，且不建立第二套项目真相或任务树。
- CoTend 原生的授权实施、验证复审、收尾恢复、模型与会话交接、能力检索和生命周期治理。
- Full 默认档、可选 Adaptive 执行档，以及不削弱产品语义、风险、验收和公开边界的统一结果合同。
- 从 `cotend-codex-r000016` 到 `r000017` 的精确前序关系和确定性公开 Plugin 包；不恢复任何 Trellis runtime、Skill、hook、状态目录或任务权威。

## 安装

按照 [README 的 GitHub Open Beta 安装说明](../../README.md#install-from-github-open-beta)添加 CoTend Marketplace 并安装 Plugin。Release ZIP 是可审计的离线包；日常安装推荐使用 README 中的 Marketplace 命令。

## 验证

本版发布前必须通过完整单元测试、仓库总检查、Plugin 包校验、提交材料一致性检查、确定性双构建与 SHA-256 校验。Release 同时提供 ZIP 和 `.sha256` 文件。

当前 r17 的确定性本地验证覆盖 10 Skills、104 个 Skill 文件、19 项能力和 446 项测试。此前 G06 的真实项目与用户验收证据保留在 r13，不会被重新标记为 r17 的外部验收。

## 已知边界

- 本版仅代表 GitHub Open Beta 发布；CoTend 尚未提交到或发布于 Public Plugin Directory。
- r17 已完成确定性验证和正式同会话产品自审，但没有单独运行新的外部模型 UAT。
- 完整生产 Desktop 生命周期和外部目录审核仍不是本版已证明能力。
- CoTend 不包含账户、托管后端、API key、数据库或自建 MCP server；Codex 平台本身的登录、网络、权限、模型和数据规则仍然适用。
