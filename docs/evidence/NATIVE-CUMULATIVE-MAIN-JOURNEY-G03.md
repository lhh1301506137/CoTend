## Negative Evidence

- A blocked Implementation evaluator prevents a cumulative pass.
- Bare `continue` and implicit AI acceptance leave the acceptance gate waiting.
- An unlabelled synthetic acceptance event is rejected.
- A changed digest, missing handoff field, invalid state, or real-user acceptance claim is rejected.
- Stage identities are checked pairwise, so an output that is not consumed by the next stage cannot pass.
