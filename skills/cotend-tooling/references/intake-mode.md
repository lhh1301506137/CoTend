# Tooling Mode: Intake

1. Capture the supplied name, link/post, claimed task and why it may matter.
2. Search `UPSTREAM-SOURCES.md` and `OPEN-SOURCE-REFERENCES/` before adding a
   record.
3. For a new lead, add a minimal authority entry. Write unknown facts and every
   corresponding `update_locator` field as `not_checked`; never invent a URL,
   release feed, version or license.
4. Add or update a concise research narrative when useful.
5. Add derived catalog metadata with `review_state: lead`,
   `adoption_disposition: unreviewed` and claim-level evidence only.
6. Stop before clone/install/execution, telemetry, dependency, network/paid
   service or product-project changes.

An article/README supplied by the user remains a lead. Intake does not prove
canonical identity, license, behavior, project fit, freshness or adoption.
