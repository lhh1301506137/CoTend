## Context

一个项目可能不断增加模块、脚本和局部测试，却没有同时证明当前功能承担的完整
职责、真实活动入口、上下游交接和累计主链。

## Observable Failure

AI 把局部基础设施或局部测试通过提升为功能步骤已经完成，并准备进入下一开发
叶子；真实入口、数据或下游交接仍未闭环。

## Mistaken Claim Versus Actual State

- mistaken: 一个候选实现和对应测试通过，因此该功能或主链步骤完成；
- actual: 只证明一个窄实现切片工作，未证明完整职责、集成、真实入口和累计链路。

## Cause And Impact

Primary cause: `framework_gap_or_ambiguity`.

局部完成证据没有与语义职责、相邻契约和累计主链绑定，半成品可能被当成步骤完成，
造成后续无法可靠衔接和返工。

## Missed Detection

- 没有在实现前从确认语义派生验收合同；
- 没有核对真实活动入口是否已切换；
- 没有验证本步骤输出是否满足下一步骤输入；
- 状态措辞没有区分局部进展与功能闭环。

## Correction

使用 Semantic Implementation Closure，把完整语义职责、真实现状、差距、纵向实现、
分层验证和实施后复审放在同一推进判定中。

## Reusable Guard

在声称功能或主链步骤完成前，同时检查完整职责、真实入口和数据、上下游契约以及
累计主链；对未闭环的轴使用精确的部分完成措辞。

## Validation

`tests/test_native_cumulative_main_journey.py` 和原生关闭链验证覆盖局部通过但相邻或
累计链仍被阻塞的情况。它们是确定性合同证据，不是所有真实项目效果的统计证明。
