# DMU Mode: Primary Takeover

Use only after the user explicitly assigns the recorded premium identity active
development responsibility. A strong model, advisor output or packet alone does
not authorize takeover.

## Entry Gate

Before product writes require:

- `model_role_decision.status: new_primary_confirmed`, replacement scope and
  explicit user confirmation;
- canonical current `full_current_project` Project Intelligence with
  implementation permission;
- the premium model's own independent end-to-end workflow/code mapping,
  off-map inspection and real verification;
- `understanding_depth: takeover_ready` with blockers/unknowns stated;
- current branch/worktree, active truth/path, risk, protected meaning, pending
  gates, verification and reliable boundary;
- explicit takeover scope, rollback and return-handoff expectation.

If the user switches modes mid-session and `TAKEOVER-PACKET.md` is absent, the
premium model may proceed only when its own fresh audit is `takeover_ready` and
it has `CONSENSUS-DELTA.md`; otherwise request a packet from the current Primary.

## Takeover Process

1. Read the common identity/depth contract, takeover packet, baseline and direct
   evidence; challenge packet claims.
2. Refresh `UNDERSTANDING-AUDIT.md`; ask only blocking user-owned product/risk
   questions.
3. Write `TAKEOVER-PLAN.md` before large edits: scope, understanding, coherent
   units, verification and rollback.
4. Implement only inside confirmed scope and canonical risk/authority bounds.
   New professional L3/L4 detail is Primary-owned; protected direction change
   returns to its owner.
5. Verify the actual end-to-end result, failure paths and current execution-
   closure boundary. A packet claim or self-report is not evidence.
6. Write `RETURN-HANDOFF.md` before returning control; update only authorized
   current truth and preserve history.

The premium model may edit code here, but cannot silently alter product
direction, erase active truth, skip verification, claim acceptance/release or
leave the previous Primary without a reconstructable return boundary.
